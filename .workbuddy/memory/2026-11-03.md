## AnswerGate v2.1 增量：pause 模式（超时暂停不退出程序）
- 用户需求（推翻 v2 kill 默认语义）：超时像按了一下空格暂停 Bilibili 播放，程序不退出；答对题后自动恢复播放
- 实现（commit fb6f627，主理人亲自实现，专家团已解散）：
  - `[monitor] timeout_action = "pause"|"kill"`（模板默认改 pause）+ `pause_key_code`（macOS 键码，默认 49 空格；Windows 固定 VK_MEDIA_PLAY_PAUSE 0xB3 忽略此值）
  - monitor::toggle_playback_key：macOS osascript 按 pid 置前 + delay 0.3 + key code（**需辅助功能权限，实测无权限报 -10004**，失败自动回退 kill 不放任）；Windows keybd_event 媒体键占位
  - gate.rs：paused 标志持久化；begin_timeup_paused（保留纳管 pid/target_id，与 kill 模式清字段相反）；extend_round 原地续期 paused=false
  - commands：handle_timeout 按配置分流；do_launch_target 前置 pause-resume 分支（进程存活→resume_target+extend_round 不重新拉起；已死→清字段落回正常 launch）
  - 前端零改动（「继续使用」按钮语义不变，后端决定 resume 或 relaunch）
  - tests/e2e_pause_flow.rs 7 条：配置解析/sanitize、状态机转移、持久化 roundtrip、真实进程 pause 不杀+terminate 仍可杀；全仓 86+1 ignored 全绿
- 坑：测试 spawn 用 child.id() 拿到的是 sh 包装进程（立即退出），真实目标 pid 须从 `$!` echo 读（沿用 monitor_test 模式）
- x86_64 .app 已重出（7.16MiB）；README §14.3 增补 pause/kill 双模式说明与软管控边界（孩子可手动切回点播放，强管控用 kill）
